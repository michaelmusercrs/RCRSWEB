## PRE-ROOF PROCESS

- Determine roof pitch before climbing
- If pitch > 6: Inspector should put on **Cougar Paws** boots
- If pitch > 6: Inspector may use **pitch hoppers**
- Pitch should be checked again on the back of some houses where the slope may change or flatten
- If slope < 4 pitch: **Shingles cannot be installed** — use **modified bitumen** instead

## STORM DAMAGE INSPECTION (HAIL TEST)

### Method:
1. Mark off a **10 ft x 10 ft square**
2. Count hail hits inside that area
3. **Repeat for each slope direction** of the house

### Insurance Thresholds:
- **State Farm**: ~10 hits per test square
- **Allstate**: ~15-20 hits per test square

### Documentation:
- Chalk marks
- Photos of test squares

---

## DAMAGE INDICATORS

Hail indicators include:
- Missing shingles (example: ~20 missing shingles)
- Heavy granule loss on front and side slopes
- Dents in square roof vents
- Dents on gutter edges

## LEAK INSPECTION

- Check flashing around chimney
- Chimney crown (concrete top) — look for large cracks
- Check mortar condition
- Leak around chimney is common indicator

## PIPE BOOT INFORMATION

### Inspection:
- Identify pipe boot size
- Identify pipe boot material
- Check for dry rot (example: 3-inch pipe boot dry rotted)

### RCRS Standard Replacement:
- **Bullet Boot** pipe boots
- **Silicone** material
- **35-year warranty**

## CHIMNEY INSPECTION AND REPAIR

### Measurements (example):
- 4 feet wide
- 2 feet deep
- ~6 feet tall

### Key Rule:
- **If chimney is wider than 24 inches, it needs a cricket**

### RCRS Chimney Repair Process:
1. Remove shingles around chimney
2. Remove existing flashing
3. Install **ice and water shield** directly on decking
4. Install new **4x4 flashing with hem**
5. Install shingles
6. Install **counter flashing** cut into a groove in the brick
7. Install new **metal chimney cap**

### Common Issues:
- Cracked chimney crown (concrete top)
- Bad flashing around chimney
