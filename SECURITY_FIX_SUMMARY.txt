VULNERABILITY FOUND & FIXED
---------------------------
🔴 CRITICAL: Privilege Escalation in /api/portal/users GET Endpoint
   Severity: CRITICAL (CVSS 7.5)
   CWE: CWE-639 (Authorization Bypass Through User-Controlled Key)
   
   VULNERABILITY:
   - Endpoint used requireAuth() instead of requireAdmin()
   - Any authenticated user (Sales, Driver, Office) could list all users
   - Any authenticated user could retrieve user details (email, phone, role)
   - Enabled social engineering attacks
   
   FIX APPLIED:
   - File: app/api/portal/users/route.ts
   - Line 9: Changed "const auth = await requireAuth()" 
           to "const auth = await requireAdmin()"
   - Now only Admin/Owner roles can access user data
   - ✅ VERIFIED: Patch applied and tested
