============================================================
MATERIAL CALCULATION FORMULAS
============================================================
These formulas are used by River City Roofing Solutions for
standard residential asphalt shingle roof replacements.

SHINGLES (GAF Timberline HDZ):
  Bundles = Roof sq ft / 33.3
  3 bundles = 1 square (100 sq ft)
  Cost: $38.50/bundle

UNDERLAYMENT (GAF FeltBuster Synthetic):
  Rolls = Roof sq ft / 400
  Cost: $62.00/roll

STARTER STRIP (GAF Pro-Start):
  Bundles = Perimeter ft / 100
  Cost: $24.00/bundle

RIDGE CAP (GAF Seal-A-Ridge):
  Bundles = Ridge ft / 25
  Cost: $56.00/bundle

DRIP EDGE (10ft White):
  Pieces = Perimeter ft / 10
  Cost: $5.50/piece

ICE & WATER SHIELD (GAF StormGuard):
  Rolls = Perimeter ft / 75 (minimum 2 rolls)
  Cost: $78.00/roll

ROOFING NAILS (1.25" Galvanized):
  Boxes = Shingle bundles / 10 (minimum 2 boxes)
  Cost: $12.50/box (5 lb)

STEP FLASHING (4x4x8"):
  Pieces = Perimeter ft x 0.15 (add 20 if multi-story)
  Cost: $1.80/piece

PIPE BOOTS (Master Flash 2"):
  Count = Number of pipe penetrations (default 3)
  Cost: $14.00/piece

ON-SITE INSPECTION CHECKLIST
============================================================
EXTERIOR - ROOF:
[ ] Shingle condition (curling, cracking, missing tabs)
[ ] Granule loss (check gutters and ground)
[ ] Hail damage (circular dents, bruised shingles)
[ ] Wind damage (lifted, creased, missing shingles)
[ ] Algae/moss growth
[ ] Flashing condition (walls, chimneys, vents)
[ ] Pipe boot condition (cracked rubber seals)
[ ] Ridge/hip cap condition
[ ] Exposed nail heads
[ ] Number of existing layers

EXTERIOR - OTHER:
[ ] Gutter condition (sagging, damage, drainage)
[ ] Downspouts (connected, proper discharge)
[ ] Soffit condition (rot, damage, ventilation)
[ ] Fascia condition (rot, paint, damage)
[ ] Siding near roofline
[ ] Chimney condition (cap, mortar, flashing)

INTERIOR / ATTIC:
[ ] Attic ventilation (ridge vent, soffit vents)
[ ] Daylight visible through decking
[ ] Water stains on decking
[ ] Mold or mildew
[ ] Insulation condition
[ ] Ceiling stains (interior rooms)
[ ] Active leaks

MEASUREMENTS TO VERIFY:
[ ] Confirm roof pitch with pitch gauge
[ ] Measure or confirm building footprint
[ ] Count all penetrations (pipes, vents, etc.)
[ ] Note all valleys, hips, ridges
[ ] Measure chimney dimensions if present
[ ] Note satellite dish/antenna locations
[ ] Check for solar panels
