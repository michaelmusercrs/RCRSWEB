## SECTION 1: SYSTEM FEATURES & FUNCTIONS

### Your Dashboard (/portal/dashboard)
Simple and focused — 4 tiles:
- Monday Notes
- Chat (GroupMe)
- My Profile
- My Deliveries

### Driver Portal (/portal/driver)
- View all your assigned deliveries for the day
- Each delivery shows: job name, customer, address, materials, priority
- Status tracking: Planned → In Progress → Delivered
- One-tap Google Maps navigation to each stop
- Real-time ETA updates

### Today's Route
- See all stops in order
- Total distance and estimated time
- "Full Route" button opens Google Maps with all stops mapped
- Progress bar showing completed vs remaining
- Each stop card shows:
  - Stop number (1, 2, 3...)
  - Status indicator
  - Job name and customer name
  - Priority badge (Normal, Rush, Urgent)
  - Address (tappable for navigation)
  - Phone number (tappable to call)
  - Item count
  - Scheduled time / ETA
  - Special instructions (if any)
  - Inspector required alert (if applicable)
  - Action buttons: Navigate, Details, Start/Complete Delivery, Photos

### Loading Checklist (/portal/driver/loading)
Before leaving the warehouse:
- Item-by-item material verification
- Check each item against the order: correct product, correct quantity
- Photo of loaded truck
- Safety checks
- Driver acknowledgment/sign-off
- This MUST be completed before starting your route

### Proof of Delivery
At each delivery stop:
- Take photo(s) of materials at delivery site
- Add delivery notes (where materials were placed, any issues)
- Mark delivery as "Complete"
- Automatic timestamp recorded
- Customer/office automatically notified

### Communication
- GroupMe chat for quick messages to office or team
- Call customer directly from delivery card (tap phone number)
- DM office staff for urgent changes
- Monday Notes for weekly schedule awareness

## SECTION 2: YOUR USE CASES — A Driver's Day

### Morning (Start of Shift)
1. Open portal on phone → tap "My Deliveries"
2. Review all assigned stops for today
3. Note any URGENT or RUSH priority deliveries
4. Check special instructions for each stop
5. Go to warehouse → start Loading Checklist

### At the Warehouse
1. Open Loading Checklist on phone
2. For each delivery:
   - Pull the listed materials
   - Check each item (right product, right quantity)
   - Load in route order (last delivery on bottom, first on top)
3. Take photo of loaded truck
4. Complete safety checks
5. Sign off on the checklist
6. Tap "Start Route" → Google Maps opens with first stop

### On the Road
1. Follow Google Maps navigation to each stop
2. Between stops: status auto-updates to "In Transit"
3. If running late or early: ETA auto-adjusts
4. If issue arises: message office via GroupMe

### At Each Delivery Stop
1. Arrive → tap "Start Delivery" on the stop card
2. Unload materials to specified location
3. Check special instructions (gate code, stacking spot, inspector needed)
4. Take photos of delivered materials
5. Add notes if needed ("Materials stacked by garage, per instructions")
6. Tap "Complete Delivery"
7. Customer and office get automatic notification
8. Move to next stop

### End of Day
1. Verify all deliveries show "Completed" status
2. Any undelivered stops? → message office with reason
3. Return to warehouse
4. Check tomorrow's route (if available)
5. Report any vehicle issues in GroupMe

## SECTION 4: HANDS-ON PRACTICE

### Exercise 1: Check Your Route (3 min)
1. Open /portal/driver
2. See how many stops you have today
3. Read the first stop: customer name, address, materials
4. Check for any special instructions
5. Tap "Full Route" → see all stops on Google Maps

### Exercise 2: Loading Checklist (5 min)
1. Open /portal/driver/loading
2. Walk through the checklist items
3. Practice checking off each item
4. Take a test photo (of anything)
5. Complete the safety checks
6. Sign off

### Exercise 3: Complete a Delivery (5 min)
1. On a delivery stop card, tap "Start Delivery"
2. Take a photo of the materials (or a test photo)
3. Add a note: "Materials placed on left side of driveway"
4. Tap "Complete Delivery"
5. Verify the status changed to "Delivered"
6. Check that the next stop is now active

### Exercise 4: Navigation (3 min)
1. Pick any delivery stop
2. Tap "Navigate" → Google Maps opens
3. Verify the address is correct
4. Check estimated drive time
5. Go back to the portal

### Exercise 5: Communication (3 min)
1. Open GroupMe chat
2. Send a message: "Testing new delivery system!"
3. Practice calling the office from the phone system
4. Send a DM to the office manager

### Troubleshooting
- **Can't see my route?** → Refresh page. If still missing, message office.
- **Wrong materials on the list?** → DO NOT deliver wrong materials. Message office immediately.
- **Customer not home?** → Check special instructions. If none, call customer (tap phone #). If no answer, message office.
- **Can't upload photo?** → Check camera permissions in phone settings. Try again. If still failing, take photos with regular camera and message office.
- **App not loading?** → Check internet connection. Try closing and reopening browser.
