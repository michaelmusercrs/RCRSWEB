## SECTION 1: SYSTEM FEATURES & FUNCTIONS

### Your Office Portal Dashboard
The office portal is your operations hub with 4 main tabs:

#### Tab 1: Dashboard
- **Active Deliveries** counter with truck icon
- **Completed Today** with check circle
- **Pending Invoices** count
- **Pending Amount $** — total outstanding dollars
- Real-time stats that refresh

#### Tab 2: Delivery Tickets
- Full table of all delivery tickets
- **Search bar** to find by job name, customer, or address
- **Status filter**: All, Planned, In Transit, Delivered, Cancelled
- Each ticket shows: Job, Customer, Status, Priority, Driver, Date
- **Actions per ticket**:
  - Assign Driver (dropdown of available drivers)
  - Pull Materials (initiates materials prep)
  - View Details (full ticket info)

#### Tab 3: Invoices
- Full table of all invoices
- **Search bar** to find by customer or invoice number
- **Status filter**: All, Pending, Sent, Paid, Overdue
- Each invoice shows: Number, Customer, Amount, Status, Date
- **Actions per invoice**:
  - Mark Paid (for pending/sent invoices)
  - View Details (full breakdown)
  - Send/Resend (email to customer)

#### Tab 4: Create Order
- Complete material order form:
  - **Job Information**: Job name, job number, address
  - **Customer Contact**: Name, phone, email
  - **Project Manager**: Who's overseeing this job
  - **Delivery Details**:
    - Preferred date and time
    - Priority level (Normal, Rush, Urgent)
    - Special delivery instructions
  - **Material Selection Grid**:
    - All 11 products with quantity selectors
    - Running total at bottom
    - Category groupings
  - Submit creates the order AND auto-generates a delivery ticket

### Scheduling & Calendar

## SECTION 2: YOUR USE CASES — An Office Staff Day

### Morning Routine (8:00 AM)
1. Open Office Portal → Dashboard tab
2. Check **Active Deliveries** — any from yesterday still pending?
3. Check **Pending Invoices** — how much is outstanding?
4. Switch to **Delivery Tickets** tab → check for unassigned tickets
5. Assign drivers to any unassigned tickets
6. Switch to **Invoices** tab → check for any new "Overdue" status
7. Check GroupMe for overnight messages

### Handling Incoming Calls (Throughout Day)
1. Caller asks about services → note their info
2. Navigate to lead entry → create new lead
3. Fill in: name, phone, email, address, service interest, source ("phone call")
4. Quick-assign to appropriate sales rep based on area/availability
5. Rep gets notification of new lead

### Processing Material Orders (As Needed)
1. PM or sales rep requests materials for a job
2. Go to **Create Order** tab
3. Fill in job information and customer contact
4. Select materials from the grid → quantities
5. Set delivery date, time, priority, and instructions
6. Submit → order created AND delivery ticket auto-generated
7. Go to **Delivery Tickets** → assign a driver to the new ticket

### Managing Deliveries (Throughout Day)
1. Monitor **Delivery Tickets** tab for status changes
2. When driver marks "In Transit" → note the time
3. If customer calls asking about delivery → check status + ETA
4. When delivery shows "Completed" → verify photos
5. Process any delivery issues or returns

### Invoice Management (Daily)
1. Check **Invoices** tab for completed jobs
2. Generate invoices for newly completed work
3. Send invoices to customers
4. When payment received → Mark Paid
5. Flag any invoices going overdue
6. Follow up on 30+ day overdue invoices

### Scheduling (As Needed)
1. Check calendar for availability
2. Schedule inspections from incoming requests
3. Coordinate delivery times with driver availability
4. Book appointments → Google Calendar link auto-generated
5. Check for scheduling conflicts

### End of Day (4:30-5:00 PM)
1. Review dashboard stats — all deliveries completed?
2. Check for any remaining unassigned tickets for tomorrow
3. Note any overdue invoices needing morning follow-up
4. Update Monday Notes with any important items
5. Quick GroupMe check for end-of-day messages

## PROCESS FLOWCHARTS

### Incoming Call → Lead Creation
```
Phone rings → Answer → Customer inquiry?
  YES → Take name, phone, email, address, service need
      → Create lead in portal (lead entry)
      → Quick-assign to available sales rep
      → Rep gets notification → follows up
  NO → Transfer to appropriate extension
```

### Material Order → Delivery → Invoice
```
PM/Rep requests materials
  → Office creates order (Create Order tab)
  → Delivery ticket auto-generated
  → Office assigns driver
  → Driver completes loading checklist
  → Driver delivers materials
  → Office sees "Completed" status
  → Office generates invoice
  → Invoice sent to customer
  → Payment received → Mark Paid
```

### Invoice Follow-Up
```
Invoice created → Status: Pending
  → Send to customer → Status: Sent
  → Wait for payment
    → Payment received → Mark Paid
    → 30 days pass → Status: Overdue
      → Follow-up call/email
      → Flag for Sara/management review
```
